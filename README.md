# Sales Performance Dashboard – Power BI
## Project Overview
This project is a **Sales Performance Dashboard** created using **Power BI** to analyze business sales data and generate meaningful insights for decision-making.
The dashboard helps in understanding:
* Revenue trends over time
* Regional sales performance
* Category-wise sales
* Product-wise sales
* Profit analysis
* Overall business performance
This project simulates a real-world business analytics task performed by data analysts.
# Tools & Technologies Used
* **Power BI**
* Microsoft Excel / CSV Dataset
* Data Cleaning using Power Query
* DAX Measures for KPIs
# Dashboard Features
## KPI Cards
The dashboard includes key business metrics:
* Total Sales
* Total Profit
* Total Quantity Sold
* Total Orders
* Profit Margin %
## Revenue Trend Analysis
A line chart is used to analyze how revenue changes over time.
Insights:
* Helps identify sales growth patterns
* Detects seasonal trends
* Tracks business performance yearly/monthly
## Region-wise Sales Analysis
A donut chart/slicer is used to compare sales across different regions.
Insights:
* Identifies high-performing regions
* Helps businesses focus on profitable locations
## Product-wise Sales Analysis

Bar charts are used to visualize top-selling products.
Insights:
* Identifies best-selling products
* Helps in inventory and marketing decisions
## Category-wise Sales Analysis
Sales are compared across categories such as:
* Technology
* Furniture
* Office Supplies
Insights:

## Profit Analysis by Sub-Category

A waterfall chart is used to analyze profit contribution from different sub-categories.

Insights:

* Identifies profitable and low-profit products
* Helps improve business strategies
